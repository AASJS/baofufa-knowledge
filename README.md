# 保富法知识库 · README

一份把聂云台《保富法》拆成**彼此链接、好查找、可交互**的知识库。核心问题只有一个——「发财不难，保财最难」，那么财富究竟怎样才能长久保住？

---

## 一、这本书讲什么

《保富法》是聂云台居士 1942—1943 年写的劝世之作，曾连载于上海《申报》，数日间收到读者助学捐款四十余万银元。作者用一生所见的中兴名臣、上海富家、家乡亲族的兴衰实例，加上自家七世祖乐山公行医济世的果报，反复印证一件事：

> 不义之财聚得越多，对后代的伤害越大；真正能保住财富与福泽的，不是精于聚敛，而是谦德、布施与智慧眼光。

它不是聚财术，而是一套「保富亦保福」的心法。

## 六、给 AI 协作者的提示

- 整理前先读 `提示词.md`、`史料/` 与 `目录.md`。
- 事实与引文严格以原文为准，不编造出处、不夸大功效、不承诺速成。
- 已存在的页面优先更新，不重复建页；新页面至少连出 2 条 `[[双向链接]]`。
- 完成后同步更新 `目录.md` 与 `日志.md`。
- 维护时检查：失效链接、孤立页面、重复页面、跨页内容矛盾。
